# 持久执行会话实施合同

日期：2026-10-03。change_id：`meerkat-persistent-sessions-20261003`。

属于 [完整设计](session-budget-coordination-20261003.md) 的工作包 02、03、04、09、13、18 的会话部分。源码基线 `df44254965844975311abf2ed1bc10e88105164a`；独立分支 `codex/rpc-session-foundation-20261003`。

目标：Go 将 Role Run 绑定到持久 Session，Pi 使用 RPC 执行并保存历史。开发与修复延续同一任务会话；每次独立审查使用新会话。正常结束后停止并回收子进程，后续 Run 通过核对后的会话文件继续；持久会话不要求空闲进程持续占用内存。

范围：通用 Executor 能力与会话合同、SQLite V4 Session / Run 绑定、私有文件核验和备份、Pi RPC 执行通道、Go 角色流程接入、检查和文档。本地直接编码，不创建子 Agent，不调用付费模型，不替换已安装版本或用户服务。

## 固定合同

- Task、Context、Profile、基准与范围保持冻结。Session 额外绑定任务合同摘要、角色、Profile 摘要、执行器、私有文件摘要、后端会话身份和最后核对 SHA。
- 调度器不解析 Pi 专有格式。Executor 声明已实现的能力并负责初始化、核验和协议转换；不声明请求预算门禁、压缩控制或脏文件恢复已经实现。
- Run 与 Session 占用在同一个短事务中持久化，再启动执行器。相同 Task / Session 不能同时执行；所有 Run 仍共用全局队列与 Worktree 排他。
- Pi 验证选定模型、会话身份、路径与空闲状态后才提交一次 prompt。接受回执、模型结束、会话空闲、进程退出与 Git 交付分别核验。提示词经私有 stdin 发送，不放进进程参数。
- 停止先封闭输入、清空队列、中止、核对空闲，再关闭输入并回收进程；必要时只终止当前拥有的进程组。无法核对的会话标为未知，不自动重放。
- 同任务的开发与修复只复用合同、Profile、文件摘要一致且 SHA 已核对的空闲会话。SHA 变化仅接受本任务已核验成功 Run 形成的连续版本推进，不接受外部提交。每次审查新建会话。改变模型或合同不静默改写旧 Session。
- 恢复仅适用于已核对的会话和干净工作区。预算自动收尾、检查点和未提交修改恢复仍按下一工作包实施。
- 重启把未确认结束的 Session 标为未知。旧 PID、残存文件或 prompt 接受回执不能单独证明可恢复。
- SQLite 保存状态与不透明文件引用；会话内容留在私有目录。公开快照、MCP、默认导出不暴露原始会话、私有路径或凭据。备份保存会话文件，校验身份与摘要；活动会话的备份明确拒绝，避免假称一致。
- 事件用量只统计当前 Run；历史会话总量不能再次计入。缺失用量保持未知，费用仅保留有来源的估算。

## 必验

开发 → 独立审查 → 修复复用 → 复审；不同任务会话隔离；并发占用拒绝；合同 / Profile / SHA / 文件不符拒绝；重复或丢失 prompt 回执不重发；agent_end 不替代 agent_settled；停止顺序与不确定退出；重启未知；私有内容脱敏；历史用量不重复计量；V1/V2/V3 到 V4 升级、备份恢复和文件损坏拒绝。

本机 Pi 使用离线元数据探测验证指定会话文件的加载与再次打开，不发出模型请求。实际模型编码、预算暂停后真实续跑和最终提交仍须后续集成验收，不能由元数据探测代替。
